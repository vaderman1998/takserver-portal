GitHub: a fine-grained personal access token with Contents: read-only on this one repository. It is kept in portal-state.json (mode 600) and never shown again. An SSH deploy key for root with a git@github.com: URL works too.

Run settings

TerraTAK has no login of its own. With a name and password set, the portal gives it a Helidon security file: everyone must sign in, only that user may change data, and ATAK devices streaming tiles need the same login. Left blank, anyone who can reach the port can use and change it, which is only sane on a private network. With HTTPS off or no certificate on the box, traffic is plain HTTP, and a browser that has visited TAK Server's 8443 on this host name will refuse it (HSTS): use the IP address then.

Snapshots

A copy of /opt/tak/certs and both CoreConfig files, kept in /root/tak-pki-snapshots. Every certificate job saves one automatically before it starts (the newest 10 of those are kept). Restoring puts every file back and restarts TAK Server. TAK's database is not included: admin grants and enrolled certificates survive either way.

Rotate Intermediate CA

Creates a new intermediate CA signed by your root CA, reissues the server and client certificates on it, and keeps the old intermediate trusted until you revoke it.

Untick to do only what the manual guide does: the server certificate moves, the certificates on disk stay on the old CA until you reissue or revoke. Either way enrolled devices are not touched. Names: letters, numbers, hyphens and dots only; an underscore makes TAK Server reject every enrolled device.

Live certificates by CA

Every client UID's newest certificate in TAK Server's certificate table, grouped by the CA that signed it. This is the list that tells you when it is safe to revoke an old CA.
